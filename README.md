BidSure AI is a prototype concept for an AI-assisted government tender management platform.

The project demonstrates how artificial intelligence and modern web interfaces could be used to help organizations manage tenders, evaluate bids, monitor compliance, and gain insights from procurement data.

⚠️ Prototype / Demo Only

This repository contains a prototype intended for demonstration, experimentation, and educational purposes. It is not a production procurement system and should not be used to make real procurement decisions.

✨ Features
📊 Tender and procurement dashboard
📝 Tender management interface
🤖 AI-assisted procurement concepts
📑 Bidder and bid information
📈 Dashboard analytics and visualizations
🔎 Tender/bid filtering and search
💾 Browser-based demo data persistence
🔐 Demonstration login interface
🖥️ Demo

The application is currently a front-end prototype and uses fictional/demo data.

No real government procurement decisions should be made using this application.

🛠️ Technology

The prototype is built using web technologies including:

HTML5
CSS3
JavaScript
Chart.js
Google Fonts

The current version is primarily a client-side prototype and does not require a production backend.

🚀 Running Locally
Option 1 — Open directly

Clone the repository:

git clone https://github.com/immackreya02/bidsure-ai-prototype.git

Enter the project:

cd bidsure-ai-prototype

Then open index.html in your browser.

Option 2 — VS Code Live Server

If you use VS Code, you can install the Live Server extension.

Then:

Open the project in VS Code.
Right-click index.html.
Select Open with Live Server.

The application should open in your browser.
